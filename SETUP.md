# Как подключить донаты

Подключай только те площадки, куда зрители реально кидают деньги. Все три могут работать одновременно.

Токены остаются на компьютере стримера в `secrets.json`. В git они не попадают.

## DonationAlerts

Это самый частый вариант.

1. Открой [настройки DonationAlerts](https://www.donationalerts.com/dashboard/general).
2. Найди **Секретный токен** (Secret token) и скопируй его.
3. Если токена на этой странице нет:
   - зайди в **Оповещения / виджет алертов**;
   - нажми **Показать ссылку для встраивания**;
   - скопируй кусок после `token=` или вставь ссылку целиком.
4. В приложении: вкладка **Донаты → DonationAlerts**.
5. Вставь токен или ссылку и нажми **Подключить DonationAlerts**.
6. В логе должно быть: `DonationAlerts: виджет подключен`.

OAuth (Client ID / Secret) нужен только если секретный токен не сработал.

## DonatePay

1. Войди на [donatepay.ru](https://donatepay.ru/) аккаунтом стримера.
2. Открой [страницу API](https://donatepay.ru/page/api).
3. Скопируй API-ключ.
4. В приложении: **Донаты → DonatePay**, вставь ключ, нажми **Подключить DonatePay**.
5. В логе: `DonatePay: вход как ...`

DonatePay отдаёт события примерно раз в 20 секунд — так устроен их API.

## Trula.io

1. Войди на [trula.io](https://trula.io/) аккаунтом стримера.
2. Открой **Виджеты → Алерты** (ссылка, которую вставляют в OBS как Browser Source).
3. Скопируй эту ссылку целиком.
4. В приложении: **Донаты → Trula**, вставь ссылку, нажми **Подключить Trula**.
5. Не бери страницу доната вида `trula.io/dp/...` — нужна именно ссылка виджета для OBS.

## Проверка без настоящего доната

На вкладке **Эффекты** нажми **Тест** у нужного эффекта. Так можно проверить флешку, дроп и остальное, ещё не привязав площадки.
