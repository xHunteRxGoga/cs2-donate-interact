# Как подключить донаты

Кнопка **«Тест»** проверяет только эффекты в CS2. Живые донаты идут другим путём: сначала нужно **привязать аккаунт** площадки.

Токены остаются на компьютере стримера в `secrets.json`. В git они не попадают.

## DonationAlerts

1. Вкладка **Донаты → DonationAlerts** (или «Как подключить»).
2. Нажми **Привязать аккаунт DonationAlerts** — откроется кабинет.
3. Войди тем же аккаунтом, куда кидают донаты.
4. Скопируй **Секретный токен** на [странице настроек](https://www.donationalerts.com/dashboard/general)
   или ссылку виджета алертов с `token=` ([виджет](https://www.donationalerts.com/dashboard/alert-widget)).
5. Вернись в приложение и нажми **OK** — токен вставится из буфера и слушатель запустится.
6. В логе: `DonationAlerts: слушатели запущены` и `сокет подключен`.
7. В кабинете DA отправь **тестовый алерт на 100₽** (сумма должна совпасть с эффектом). Через 3 секунды успей в CS2.

OAuth (Client ID / Secret) нужен только если секретный токен не сработал.

## DonatePay

Нужны **оба** куска — иначе донат может прийти с задержкой или не прийти.

1. Нажми **Привязать аккаунт DonatePay**.
2. Со страницы [оповещений](https://donatepay.ru/donation/notifications/) скопируй ссылку виджета:
   `https://widget.donatepay.ru/alert-box/widget/...`
3. Со страницы [API](https://donatepay.ru/page/api) скопируй API-ключ.
4. Вставь оба поля и нажми **Подключить DonatePay**.
5. В логе: `DonatePay: вход как ...` и/или `subscribed notifications#...`

Виджет даёт донат сразу. API — подстраховка раз в несколько секунд.

## Trula.io

У Trula нет публичного OAuth для сторонних программ. Привязка — через ссылку виджета из кабинета.

1. Нажми **Привязать аккаунт Trula**, войди.
2. **Виджеты → Алерты** — скопируй ссылку, которую вставляют в OBS как Browser Source.
3. Вернись, нажми **OK**.
4. Не бери страницу доната `trula.io/dp/...` — нужна именно OBS-ссылка алерта.

## Проверка без настоящего доната

Для дропа, мыши и гранаты запускай **`run-admin.bat`**. Если Windows покажет «неизвестный издатель» — жми **Запустить**.

Без прав администратора CS2 часто просто игнорирует клавиши — флешка и вылет игры при этом работают.

На вкладке **Эффекты** нажми **Тест**. Появится отсчёт 3 секунды — сразу перейди в CS2. Внизу экрана всплывёт табличка с именем и эффектом.

Если донат не сработал, а тест сработал: вкладка **Лог** → **Скопировать лог**. Там должно быть `донат:` — если этой строки нет, площадка ещё не привязана или токен не тот.

Для гранаты в CS2 клавиша слота должна быть именно **HE** (по умолчанию `4`), не вспышка. Тестируй стоя на земле с гранатой в инвентаре.
