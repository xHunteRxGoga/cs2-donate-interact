# CS2 Donate Interact

Приватный инструмент для стримера: донат определённой суммы запускает эффект в CS2. Это не чит и не чтение памяти игры. Приложение слушает DonationAlerts, DonatePay и Trula.io и шлёт обычный ввод Windows — тот же `SendInput`, которым пользуются AHK-скрипты из роликов вроде [этого](https://www.youtube.com/watch?v=HECT8YMu-Ks).

Python здесь удобнее чистого AHK: нормальная панель настроек, WebSocket донатов, очередь, кулдауны и аварийный стоп.

## Эффекты по умолчанию

| Сумма | Эффект |
| --- | --- |
| 100₽ | Белая флешка на весь экран на 8 секунд |
| 200₽ | Дроп оружия (`G`) |
| 300₽ | Резкий рывок мыши — «срыв сенсы» |
| 400₽ | WASD не работают 10 секунд |
| 500₽ | Выбор гранаты, взгляд в пол, бросок и присед |
| 1000₽ | Принудительное закрытие CS2 |
| 10000₽ | CS2 закрывается, на весь экран идёт Minecraft-летсплей. Выключить можно только `Alt+5` |

Все суммы, длительности, клавиши и кулдауны меняются в приложении.

## Как запустить

1. Установи [Python 3.11+](https://www.python.org/downloads/) и отметь **Add python.exe to PATH**.
2. Для эффектов с клавишами (дроп, сенса, граната, WASD) дважды нажми `run-admin.bat`. Если вылезет предупреждение «неизвестный издатель» — жми **Запустить**. Обычный `run.bat` годится для настройки, но CS2 может игнорировать G.

```bat
python -m pip install -r requirements.txt
python -m src.main
```

3. В CS2 поставь режим отображения **«Во весь экран в окне»**. Иначе белый оверлей может оказаться под игрой. Гамма-вспышка иногда проходит и через exclusive fullscreen, но не на всех видеокартах и не в HDR.
4. Проверь эффекты кнопками **Тест**, уже без донатов.
5. Для 10000₽ положи ролик в `assets/minecraft_letsplay.mp4` или укажи путь в настройках. Надёжнее локальный файл. Для YouTube нужен [mpv](https://mpv.io/).

При запуске и раз в ~45 минут программа сама смотрит [репозиторий](https://github.com/xHunteRxGoga/cs2-donate-interact). `config.json`, `secrets.json` и видео в `assets/` не затираются. Во время стрима окно само не закрывается — в шапке будет **GH: перезапуск**. Git-клон с локальными правками не трогает. Выключить: вкладка **Кулдауны и работа**.

## VAC

Это не чит: программа не лезет в память CS2, не подменяет файлы игры и не рисует wallhack. Она работает снаружи, как клавиатура и AHK. Стримеры такое используют годами. VAC ищет читы внутри процесса игры, поэтому обычный бан за такой интерактив маловероятен. 100% гарантию никто не даст: правила Valve могут измениться. Не ставь это вместе с читами.

## Как привязать донаты

Подробные шаги: [SETUP.md](SETUP.md). Кнопка **Тест** не проверяет DonationAlerts/DonatePay/Trula — только эффект в CS2.

На вкладке **Донаты** открой кабинет, вставь токен/ссылку и нажми **Сохранить и проверить связь**. Успех — только зелёный статус **«подключено»**, не факт что поле не пустое.

- **DonationAlerts:** [настройки](https://www.donationalerts.com/dashboard/general) → **Секретный токен** или ссылка виджета с `token=`.
- **DonatePay:** [виджет оповещений](https://donatepay.ru/donation/notifications/) **и** [API-ключ](https://donatepay.ru/page/api).
- **Trula:** ссылка панели `https://trula.io/cp/?token=…` (её же в OBS). Страница `/dp/...` не подойдёт.

Можно включить одну площадку или все сразу. Токены пишутся в `secrets.json` и не попадают в git.

Проверка без кабинета: **Проверить табличку** или `http://127.0.0.1:8765/donate?amount=100`.

Любой донат, который приложение увидело, даёт звук и табличку снизу. Если в логе нет `приложение увидело донат` — токен/ссылка не те или связь не зелёная.

С FACEIT и античитом клавиши в CS2 часто не доходят. Табличка, звук и гамма-вспышка должны. CS2 — **«Во весь экран в окне»**, иначе табличка спрячется под игрой.

## Кулдауны и режимы

- **Глобальный кулдаун** — пауза между любыми эффектами.
- **Кулдаун эффекта** — пауза именно этого эффекта.
- **exact** — срабатывает только эта сумма: 100₽ не запустит эффект на 101₽. Если несколько эффектов всё же рядом, берётся ближайший, а не более дорогой.
- **threshold** — берётся самый дорогой эффект, который донат покрывает. 250₽ в этом режиме даст дроп, не флешку.
- **queue / skip / replace** — копить эффекты, игнорировать новые, пока идёт текущий, или заменять очередь.
- Можно требовать, чтобы CS2 была запущена или была в фокусе.

## Аварийные клавиши

- `Alt+5` — снять флешку, вернуть WASD, закрыть летсплей, очистить очередь.
- `Ctrl+Alt+5` — полностью выключить эффекты, пока не нажмёшь «Включить эффекты».

Комбинации меняются в настройках.

## Клавиши CS2

Если у тебя свои бинды, пропиши их во вкладке **Клавиши CS2**. Для гранаты лучше отдельный HE-бинд, а не колесо `4`: иначе может улететь флешка или смок.

## Важно

- Запускать только на ПК стримера и только с его согласия.
- Это локальная автоматизация ввода, не аим и не работа с памятью. VAC обычно не трогает такие стримерские скрипты, но ответственность на том, кто запускает.
- 10000₽ специально нельзя закрыть обычным `Esc` / `Alt+F4`. Аварийный стоп всегда должен быть известен стримеру.
- Не коммить `secrets.json` и `config.json`.
